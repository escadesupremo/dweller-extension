Privacy Policy

Vault Dweller · last edited 21 Nov 2026 · for version 1.0.0 and later · kristof.domokos.szabo@gmail.com

The short version
  • No data is collected. The extension contains no analytics, telemetry, tracking or advertising code.
  • Vault data goes to your Vault. Requests are made to the Vault you are signed in to, using your existing session.
  • Your session is not stored. It is read when needed and used only for requests to that Vault.
  • No other site is contacted. Query results, document contents and field values remain in the browser.

What's stored on your device

The following is held in Chrome's local extension storage on your device. None of it is transmitted.

  • Vault domain, for reconnecting to the same Vault
  • Query history, for re-running recent VQL
  • Saved query tabs, for keeping the full-window editor's open queries between sessions; closing a tab deletes its query
  • Cached Vault metadata and counts: object and document-type definitions, document counts per type, and how often each field is filled in (worked out from a small sample of records; only the percentages are kept), for browsing the data model (including the objects you opened recently), ranking fields and autocomplete without fetching them again
  • Display settings: Field Names or Labels, the row Limit, panel layout and editor height

to delete it → Clear deletes query history; uninstalling removes all stored data.

Your Vault session

The extension reads the Veeva Vault session cookie (TK) for the domain you are signed in to, and uses it to authenticate requests to that same Vault.

  • Not sent to any other destination
  • Not stored by the extension
  • No cookie read from any other site

Requests go only to the Vault you are signed in to. The extension contacts no other site and has no server of its own.

What we do not do

  • Sell or transfer data to third parties for advertising or any unrelated purpose.
  • Use data for creditworthiness or lending purposes.
  • Use data for any purpose unrelated to the extension's single function: working with Veeva Vault data and its API.
  • Retain data. None is collected, so none is held, shared or exposed.

Also

Children. The extension is a professional developer tool and is not directed at children.
